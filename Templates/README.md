# 템플릿 (Templates)

> 문서 형식을 통일하기 위한 템플릿 모음.

## Templates

| 템플릿 | 용도 |
|---|---|
| [주제 문서 템플릿 (Topic Template)](Topic-Template.md) | 개별 개념, 알고리즘, 이론, 기술 문서를 작성할 때 사용 |
| [영역 README 템플릿 (Area README Template)](Area-README-Template.md) | 새 분야 폴더의 README를 만들 때 사용 |

## Rules

- 새 주제 문서는 `Topic-Template.md`의 메타데이터 필드를 유지한다.
- 새 영역 README는 추천 학습 순서, 하위 영역, 관련 영역을 명시한다.
- 파일명은 영어 `Title-Kebab-Case`를 사용한다. 예: `Data-Structures/`, `Gradient-Descent.md`
- 표시 제목은 `한글 (English)` 형식을 우선한다.
