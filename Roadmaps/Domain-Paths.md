# 분야별 진입과 연결 (Domain Paths)

> 경로는 본문을 읽는 선택 가능한 순서다. 분야의 중요도나 저장소 작성 순서를 결정하지 않는다.

## 현재 가용성

기존 분야에는 Draft 이상 본문이 있지만 출처·예제·해설의 충분성은 문서마다 다르다. 새 영역의 전용 본문은 Planned다. 아래 표의 목표는 학습할 방향이지 현재 저장소만으로 모두 달성 가능하다는 약속이 아니다. 자세한 공백은 [전체 지식 범위](../Maintainers/Curriculum-Coverage.md)에 남긴다.

## 시작점 선택

프로그래밍이 처음이면 [입문자 경로](Beginner.md)를 사용할 수 있다. 이미 필요한 선수지식을 갖췄다면 해당 분야로 바로 들어간다. HCI·사회·교육의 모든 주제에 프로그래밍 경로 완주를 요구하지 않는다. 학위·직업에 관계없이 아래 확인 과제로 시작 수준을 판단한다.

순서는 화살표로 표시한다. 필요한 기초만 보충하고 기존 본문을 재사용한다. **빈 부분**은 인접 문서로 대체 완료 처리하지 않는다.

## 분야 이동 예시

- 선형대수의 행렬·SVD는 AI뿐 아니라 그래픽스·수치계산에서 재사용한다. 분야별 예시는 다르게 추가하되 정의를 복제하지 않는다.
- 운영체제의 스케줄링에서 임베디드 실시간 설계로 이동할 때 평균 응답시간과 마감시간 보장을 구분한다.
- 소프트웨어 테스트에서 HCI 평가로 이동할 때 명세 충족과 실제 사용자의 목표 달성을 구분한다.
- 통계적 추론은 ML뿐 아니라 성능 실험·사용자 평가·교육 연구에도 연결된다. 각 분야의 가정과 연구 윤리는 별도로 학습한다.

## 경로를 사용하는 방법

1. 결과물 하나와 필요한 깊이(입문·핵심·심화·연구 연결)를 정한다.
2. 확인 과제를 시도해 부족한 선수지식만 되돌아간다.
3. 본문을 읽은 뒤 입력·가정이 다른 사례로 다시 확인한다. 정답·해설이 없으면 스스로 확인한 범위를 노트에 명시한다.
4. Planned 구간에서 이 저장소만으로 경로가 완성됐다고 판단하지 않는다. 외부 자료와 추가 조사 질문을 기록한다.
5. 다음 분야는 직업명이 아니라 해결하려는 문제에 따라 선택한다.
