# 학습 로드맵 (Roadmaps)

> 하나의 본문 집합 위에 여러 학습 경로를 연결하는 안내서. 경로가 전체 지식 범위나 작성 우선순위를 결정하지 않는다.

## 읽는 법

- 로드맵의 순서는 기본 선수지식 흐름이다. 이미 아는 내용은 건너뛰고, 부족한 내용은 해당 섹션 README의 주제 목록으로 내려간다.
- 링크가 걸린 `Draft` 이상 문서는 지금 읽을 수 있다. `Planned`로 표시된 파일명은 아직 본문이 없는 예정 주제다.
- 각 로드맵의 `완료 기준`은 다음 단계로 넘어가기 전 점검 목록이다.
- 관심 분야가 명확하고 필요한 선수지식을 갖췄다면 바로 진입한다. HCI·사회·교육의 모든 주제에 프로그래밍 입문 완주를 요구하지 않는다.
- 학부·대학원·교수로 본문을 복제하지 않는다. 주제별 입문·핵심·심화·연구 연결에서 필요한 깊이를 고른다.

## 현재 가용성

기존 경로가 연결하는 주제에는 `Draft` 이상 본문이 있다. 새 영역에는 `Planned`도 있으며, 전용 본문이 없는 구간을 기존 경로로 대체 완료 처리하지 않는다. [분야별 진입과 연결](Domain-Paths.md)이 전체 탐색의 시작점이다. 출처·예제 확인 범위는 [준비 가이드](../Maintainers/Preparation-Guide.md)와 [전체 자료 목록](../Maintainers/Preparation-Inventory.md), 학문적 공백은 [전체 지식 범위](../Maintainers/Curriculum-Coverage.md)를 본다.

| 로드맵 | 현재 상태 | 권장 사용법 |
|---|---|---|
| [분야별 진입과 연결](Domain-Paths.md) | 기존 본문과 Planned 구간 구분 | 분야별 출발점·확인 과제·연결을 비교한다 |
| [입문자 (Beginner)](Beginner.md) | Draft 이상 본문 연결 | 공통 기초의 설명과 실습 재료를 찾는다 |
| [CS 핵심 (CS Core)](CS-Core.md) | Draft 이상 본문 연결 | 시스템·이론 중심의 기초 경로를 확인한다 |
| [AI 핵심 (AI Core)](AI-Core.md) | Draft 이상 본문 연결 | 수학부터 AI/ML 모델까지 설명 재료를 찾는다 |
| [시스템 엔지니어](Systems-Engineer.md) | Draft 이상 본문 연결 | 시스템/운영 설계와 장애 사례의 보강 대상을 찾는다 |
| [ML 엔지니어](ML-Engineer.md) | Draft 이상 본문 연결 | 모델 운영과 배포 자료를 고른다 |
| [연구자 (Researcher)](Researcher.md) | 분야별 기존 자료 연결; 공통 연구 방법은 Planned | 연구 방법을 선택하고, AI 이론은 선택 분기로 읽는다 |
