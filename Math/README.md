# 수학 (Math)

> CS와 AI를 이해하는 데 필요한 수학적 토대.

**선수지식**: 없음 (고등학교 수학 수준에서 시작 가능)

---

## 주제 목록

| 주제 | 폴더 | CS/AI 연관성 |
|---|---|---|
| 이산수학 (Discrete Mathematics) | [Discrete/](Discrete/) | 알고리즘, 논리, 집합론, 그래프 이론의 기반 |
| 선형대수 (Linear Algebra) | [Linear-Algebra/](Linear-Algebra/) | 머신러닝, 딥러닝, 그래픽스의 핵심 |
| 확률과 통계 (Probability & Statistics) | [Probability-Statistics/](Probability-Statistics/) | ML 모델, 베이즈 추론, 통계적 학습 |
| 미적분 (Calculus) | [Calculus/](Calculus/) | 역전파, 최적화 알고리즘의 기반 |
| 최적화 (Optimization) | [Optimization/](Optimization/) | 경사 하강법, 볼록 최적화, ML 학습 |
| 실해석학 (Real Analysis) | [Real-Analysis/](Real-Analysis/) | 수렴, 연속성, 함수 이론의 엄밀한 기반 |
| 수치 해석 (Numerical Methods) | [Numerical-Methods/](Numerical-Methods/) | 수치 적분, 행렬 연산, 부동소수점 |

## 학습 순서

```
이산수학 → 선형대수 → 확률/통계 → 미적분 → 최적화
                                              ↓
                                         실해석학 (심화)
```
