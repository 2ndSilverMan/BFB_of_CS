# 실무 공학 (Engineering)

> 전공지식을 실제 소프트웨어와 시스템으로 구현하기 위한 공학 계층.

## Areas

| 주제 | 역할 |
|---|---|
| [Git과 GitHub (Git and GitHub)](Git-and-GitHub/) | 버전 관리, 협업, PR, 브랜치 전략 |
| [테스트 (Testing)](Testing/) | 단위 테스트, 통합 테스트, 테스트 전략 |
| [디버깅 (Debugging)](Debugging/) | 디버깅 방법론, 로깅, 관찰성 |
| [시스템 설계 (System Design)](System-Design/) | 확장성, 가용성, 일관성, 아키텍처 설계 |
| [성능 공학 (Performance Engineering)](Performance-Engineering/) | 프로파일링, 최적화, 병목 분석 |
| [데브옵스 (DevOps)](DevOps/) | CI/CD, 배포, 운영 자동화 |
| [클라우드 (Cloud)](Cloud/) | 클라우드 컴퓨팅, 인프라, 관리형 서비스 |
| [클린 코드 (Clean Code)](Clean-Code/) | 가독성, 유지보수성, 리팩터링 |
| [디자인 패턴 (Design Patterns)](Design-Patterns/) | 반복되는 설계 문제와 해결 패턴 |
