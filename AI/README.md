# 인공지능 (Artificial Intelligence)

> 인공지능, 머신러닝, 딥러닝, 생성 모델, AI 시스템 지식.

`AI`는 수학적 기초에서 시작해 고전 머신러닝, 딥러닝, 확률 모델, 강화학습, 생성 모델, LLM, 안전성, 배포까지 이어지는 전공 지식을 다룬다.
