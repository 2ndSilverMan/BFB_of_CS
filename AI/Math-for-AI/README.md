# AI를 위한 수학 (Math for AI)

> AI를 공부하기 위해 어떤 수학을 어떤 순서로 봐야 하는지 정리하는 허브.

기본 수학 본문은 [기초 지식 (Foundations)](../../Foundations/)에 둔다. 이 폴더는 AI 관점에서 필요한 수학을 다시 묶고, 고급 수학 주제로 이어지는 길을 제공한다.

---

## Core Prerequisites

| 주제 | 위치 | AI에서 쓰이는 곳 |
|---|---|---|
| 선형대수학 (Linear Algebra) | [Foundations/Linear-Algebra](../../Foundations/Linear-Algebra/) | 벡터 표현, 행렬 연산, 임베딩, SVD |
| 미적분학 (Calculus) | [Foundations/Calculus](../../Foundations/Calculus/) | 미분, 역전파, 최적화 |
| 확률과 통계 (Probability and Statistics) | [Foundations/Probability-and-Statistics](../../Foundations/Probability-and-Statistics/) | 분포, 추정, 베이지안 모델, 일반화 |
| 최적화 (Optimization) | [Foundations/Optimization](../../Foundations/Optimization/) | 손실 최소화, 제약 최적화, SGD |
| 수치해석 (Numerical Methods) | [Foundations/Numerical-Methods](../../Foundations/Numerical-Methods/) | 안정성, 부동소수점, 대규모 계산 |

---

## Advanced Math for AI

| 주제 | 사용되는 영역 |
|---|---|
| 측도론 (Measure Theory) | 확률론, 일반화 이론, 확률 과정 |
| 함수해석학 (Functional Analysis) | 커널 방법, 함수공간, 최적화 이론 |
| 정보이론 (Information Theory) | 엔트로피, KL divergence, 표현 학습 |
| 미분기하학 (Differential Geometry) | manifold learning, information geometry |
| 범주론 (Category Theory) | 추상 구조, 프로그래밍 언어, compositional AI |

---

## Role

이 폴더는 중복 본문을 만들기보다 `Foundations`와 `AI` 사이를 연결하는 역할을 한다.
