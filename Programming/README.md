## 학습 순서

현재 바로 읽을 수 있는 최소 경로:

```text
변수와 타입 → 조건문/반복문 → 함수와 재귀 → 배열과 문자열
                                                     ↓
                               포인터와 메모리 ← OOP / 함수형 입문
```

`포인터와 메모리`, `OOP`, `함수형 입문`은 후속 확장 주제다. 입문자 로드맵을 먼저 따라갈 때는 `배열과 문자열`까지 읽고 [Data-Structures/](../Data-Structures/)로 넘어가면 된다.
