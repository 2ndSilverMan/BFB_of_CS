# 최적화 (Optimization)

> **레벨:** 학부 기초 — 최적화 문제의 구조와 핵심 알고리즘을 직관적으로 이해하는 것이 목표.
> **선수 지식:** 미적분학, 선형대수학
>
> 이 폴더는 학부 수준의 기초 최적화와 직관적 알고리즘 이해를 담당한다.
> 볼록 최적화 쌍대 이론, LP/QP/SDP, 수렴 속도 분석, 온라인/비볼록 최적화 등 대학원 수준 이론은 [최적화 이론 (Optimization Theory)](../../AI/Optimization-Theory/)에서 관리한다.
