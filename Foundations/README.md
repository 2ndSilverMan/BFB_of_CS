# 기초 지식 (Foundations)

> CS와 AI를 배우기 전에 필요한 기반 지식 계층.

`Foundations`는 수학만 모아두는 폴더가 아니라, 컴퓨터공학과 AI 전체를 이해하기 위한 공통 선수지식을 담는다.

---

## Recommended Order

| # | 주제 | 역할 |
|---|---|---|
| 1 | [프로그래밍 기초 (Programming Fundamentals)](Programming-Fundamentals/) | 변수, 제어문, 함수, 메모리, 기본 구현 감각 |
| 2 | [이산수학 (Discrete Mathematics)](Discrete-Mathematics/) | 논리, 집합, 관계, 그래프, 조합론, 정수론 |
| 3 | [선형대수학 (Linear Algebra)](Linear-Algebra/) | 벡터, 행렬, 선형변환, 고유값, SVD |
| 4 | [미적분학 (Calculus)](Calculus/) | 극한, 미분, 적분, 다변수 미적분 |
| 5 | [확률과 통계 (Probability and Statistics)](Probability-and-Statistics/) | 확률변수, 분포, 추정, 검정, 통계적 사고 |
| 6 | [최적화 (Optimization)](Optimization/) | 최적화 문제, 경사하강법, 제약 최적화 |
| 7 | [수치해석 (Numerical Methods)](Numerical-Methods/) | 부동소수점, 수치해석, 선형계, ODE/PDE 계산 |

---

## Advanced Foundations

| 주제 | 역할 |
|---|---|
| [실해석학 (Real Analysis)](Real-Analysis/) | 해석학, 수렴, 함수공간, 엄밀한 미적분 기반 |
| [복소해석학 (Complex Analysis)](Complex-Analysis/) | 복소함수, 해석함수, 적분, 변환 |
| [위상수학 (Topology)](Topology/) | 위상공간, 연속성, 연결성, 추상 구조 |
| [신호와 시스템 (Signals and Systems)](Signals-and-Systems/) | 신호, 시스템, 푸리에 분석, 필터링 |
| [디지털 신호 처리 (Digital Signal Processing)](Digital-Signal-Processing/) | FFT, 디지털 필터 설계, 스펙트럼 분석, 웨이블릿, 적응 필터 |

---

## How This Connects

- `CS/Algorithms`는 `Discrete Mathematics`와 `Programming Fundamentals`에 의존한다.
- `CS/Computer-Architecture`와 `CS/Operating-Systems`는 프로그래밍과 이산수학에 의존한다.
- `AI/Machine-Learning`은 `Linear Algebra`, `Calculus`, `Probability and Statistics`, `Optimization`에 의존한다.
- `AI/Deep-Learning`은 선형대수, 미적분, 최적화, 확률을 모두 사용한다.
