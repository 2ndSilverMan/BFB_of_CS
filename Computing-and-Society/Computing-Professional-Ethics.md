# 전문직 윤리와 책임 (Computing Professional Ethics)

- Level: Beginner
- Prerequisites: 선수 전공 없음; 사례의 기술 조건은 필요한 만큼 보충
- Status: Draft
- Reviewed-by: -
- Depth: Deep-dive (사례 분석과 판단 기준)

---

## 개념 (Concept)

전문직 윤리는 기술적으로 가능한 선택 중 무엇을 해야 하는지, 누구에게 어떤 책임을 지는지 근거를 들어 판단하는 활동이다. 법률 준수, 조직 규칙, 직업적 책임은 겹치지만 같은 질문은 아니다. 이 문서는 윤리적 판단을 기록하는 방법과 가상 사례를 다루며 법률 자문을 제공하지 않는다.

## 직관 (Intuition)

“요청한 기능을 정확히 만들었다”는 사실만으로 책임이 끝나지 않는다. 누가 요청에서 제외됐는지, 오류가 누구에게 집중되는지, 피해자가 이의를 제기할 수 있는지도 제품의 결과를 바꾼다. 반대로 선한 의도만으로 설계의 피해를 없앨 수도 없다.

## 이론 (Theory)

결과 중심 판단은 기대 이익·피해와 분포를, 권리·의무 관점은 해서는 안 되는 침해와 책임을, 절차 관점은 참여·설명·이의제기의 공정성을 묻는다. 하나의 관점으로 모든 갈등을 자동 해결하지 않는다. [ACM 윤리 강령](https://www.acm.org/code-of-ethics)은 공익, 위해 방지, 정직, 프라이버시를 전문직 판단과 연결하는 참고 기준이다. 특정 선택을 강령 한 문장으로 정당화하는 대신 실제 영향을 설명해야 한다.

판단 기록에는 사실·가정·가치·대안을 구분한다. 예를 들어 오류율 2%는 측정 범위가 있는 사실일 수 있지만 “충분히 낮다”는 피해의 심각성과 허용 기준을 포함한 판단이다. 발생 확률×피해 규모 계산도 유용할 수 있으나, 심각한 권리 침해를 다른 사람의 작은 이익과 마음대로 상쇄하는 도구로 쓰지 않는다.

## 구현 (Implementation)

가상 대학이 출결 관리를 위해 강의실 얼굴 인식을 도입하려 한다. 다음은 실제 도입 결정이나 특정 집단의 행동 추정이 아닌 교육용 분석이다.

| 질문 | 검토 기록 |
|---|---|
| 목표 | 출결 입력 부담을 줄이고 대리 출석을 줄임 |
| 이해관계자 | 학생·교원·운영자·장비업체·이의제기 담당자 |
| 불확실성 | 조명·카메라·개인 조건별 오류, 데이터 유출 영향, 대체 절차 비용 |
| 피해 가능성 | 잘못된 결석 처리, 감시 위축, 민감한 식별 자료의 불필요한 축적 |
| 대안 | 수동 확인, 일회용 수업 코드, 자기신고와 표본 확인 |
| 복구·책임 | 오류 정정 경로, 불이익 유예, 기록 담당자와 접근 권한 |
| 중단 조건 | 유효성·필요성·권리 보호를 입증하지 못하면 도입 보류 |

설계 메모의 잠정 결론은 “편의성만으로 얼굴 인식이 필요하다고 결론 낼 수 없다. 더 적은 데이터를 쓰는 대안부터 비교하고 실제 적용 전 기관·관할 규정을 확인한다”가 될 수 있다. 반대 결론을 주장하려면 대안의 부족, 피해 완화, 이의제기 절차, 잔여 위험을 구체적으로 입증해야 한다.

실무의 산출물은 다음 다섯 항목이다.

1. 목표와 기술적으로 확인된 범위.
2. 영향을 받지만 결정에 참여하지 못하는 사람.
3. 두 개 이상의 실질적 대안과 선택하지 않은 이유.
4. 책임 주체, 되돌리기·정정·신고 경로.
5. 판단을 바꿀 새로운 증거와 재평가 시점.

## 복잡도 (Complexity)

이해관계자 수만 세어 해결할 수 없고 권력·정보 비대칭을 다뤄야 한다. 점수표의 가중치를 바꾸면 결론이 달라질 수 있으므로 가중치와 근거를 숨기지 않는다. 시간·예산 제한은 검토를 축소할 수 있지만, 불확실성이 큰 부분을 확인된 것처럼 쓰는 근거가 되지는 않는다.

## 응용 (Applications)

서비스 출시, 장애 공지, 데이터 수집, 보안 취약점 보고, 연구 공개 범위에 적용한다. 허가 없는 시스템 접근을 공익이라는 말만으로 정당화하지 않고 승인된 보고·검증 경로를 사용한다.

## 흔한 오해 (Common Misunderstandings)

- 법에 명시적 금지가 없으면 윤리 문제도 없다: 법과 윤리의 범위는 같지 않다.
- 이용약관에 동의했으면 책임이 끝난다: 이해 가능성·선택권·예측하지 못한 피해를 따져야 한다.
- 모든 선택을 수치화하면 객관적이다: 측정·가중치·누락된 사람도 판단의 일부다.

## TMI

- 윤리 기록은 사건 후 변명을 위한 문서가 아니라 어떤 증거가 결정을 바꿀지 미리 적는 도구다.
- 모델 정확도 개선과 이의제기 절차 개선은 서로 다른 위험을 줄인다.

## 연습 / 확인 문제 (Exercises)

1. 가상 사례에서 동의 화면만 추가하면 해결되는가? **판단 기준:** 거절 가능한 대안, 불이익, 이해 가능성, 데이터 수명주기를 언급한다.
2. 오류율은 같지만 한 대안의 오류가 즉시 복구되고 다른 대안은 장학금에 영향을 준다면? **답:** 동일 오류율만으로 동등하다고 판단할 수 없다.
3. 반대 입장에서 위 잠정 결론을 비판하라. **평가 기준:** 근거·가정·대안을 분리하고 피해자의 관점과 잔여 위험을 포함한다.
