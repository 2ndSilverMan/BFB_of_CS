## 개념 (Concept)

회로는 전압·전류와 소자의 관계를 연결해 에너지와 신호의 흐름을 계산하는 모델이다. 디지털 값 0과 1도 실제로는 전압 구간이며, 전압·전류 한계를 넘으면 논리적으로 맞는 프로그램도 동작하지 않을 수 있다. 여기서는 집중소자 모델, 저항 네트워크, RC 과도응답과 디지털 입력의 경계를 다룬다. 고주파 전송선·전자기장·반도체 소자 물리는 후속 범위다.

## 직관 (Intuition)

전압 분배기의 출력은 고정된 숫자를 내보내는 함수가 아니다. 뒤에 연결한 회로도 전류를 가져가므로 결과가 달라진다. “측정값을 읽는다”는 행위조차 입력 저항과 커패시턴스를 추가할 수 있다. 회로도에서 생략한 부하가 소프트웨어의 숨은 의존성과 비슷하다.

## 이론 (Theory)

노드 전압은 선택한 기준점에 대한 전위차다. 이상적인 저항은 $V=IR$, 소비 전력은 $P=VI=I^2R$로 계산한다. 집중소자 가정 아래 KCL은 노드로 들어오고 나가는 전류의 합이 0이라는 제약이고, KVL은 닫힌 경로의 전압 변화 합이 0이라는 제약이다. 회로 분석 범위는 [MIT 6.002](https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/)의 저항·저장소자·디지털 추상화와 연결된다.

전원 $V_s$, 위쪽 저항 $R_1$, 아래쪽 저항 $R_2$인 무부하 분배기는 $V_o=V_sR_2/(R_1+R_2)$다. 출력에 부하 $R_L$을 연결하면 아래쪽 저항은 $R_2R_L/(R_2+R_L)$로 바뀐다. 입력을 구동할 때에는 수신기의 VIH/VIL 조건과 송신기의 VOH/VOL 보장값을 함께 확인한다. 실제 한계는 부품 데이터시트 조건에 따른다.

커패시터는 $i=C\,dv/dt$로 전압 변화를 제한한다. 처음 0V인 이상적인 직렬 RC에 DC 전압을 가하면 $v_C(t)=V_s(1-e^{-t/(RC)})$다. 시정수 $RC$는 정상상태 도달 시간이 아니라 지수 응답의 척도다. MOSFET도 완벽한 스위치가 아니다. 온 저항·게이트 전하·전압 정격이 있고, 상세 계산에는 해당 소자의 모델이 필요하다.

## 구현 (Implementation)

다음 수치는 교육용 가정이다. 3.3V 전원, 10kΩ/10kΩ 분배기 출력에 10kΩ 부하를 연결해 보자.

- 무부하: 1.65V.
- 부하 연결: 아래쪽 등가 저항 5kΩ, 출력 1.10V.
- 상단 전류 0.22mA는 하단 저항과 부하로 각각 0.11mA씩 나뉜다.
- 수신기가 최소 2.0V를 high로 요구한다는 가정이면 두 경우 모두 high를 보장하지 못한다.

Python 표준 라이브러리로 실행할 수 있는 계산 모델이다. 실제 회로 시뮬레이터나 측정값이 아니다.

```python
from math import exp, isclose, log

vs, r1, r2, load = 3.3, 10_000, 10_000, 10_000
parallel = r2 * load / (r2 + load)
unloaded = vs * r2 / (r1 + r2)
loaded = vs * parallel / (r1 + parallel)
assert isclose(unloaded, 1.65)
assert isclose(loaded, 1.10)
assert isclose((vs - loaded) / r1, loaded / r2 + loaded / load)

r, c = 1_000, 1e-6
tau = r * c
v_at_tau = vs * (1 - exp(-1))
t90 = -tau * log(0.1)
assert isclose(tau, 0.001)
assert 2.302 < t90 * 1000 < 2.303
assert 2.085 < v_at_tau < 2.087
print(round(loaded, 2), round(t90 * 1000, 3))  # 1.1 2.303
```

## 복잡도 (Complexity)

두 저항의 계산은 작지만 실제 문제의 비용은 모델 선택에 있다. 큰 선형 회로는 노드 방정식의 선형계로 풀 수 있고, 비선형 소자는 반복 계산이 필요하다. 저항 허용오차·전원 변동·온도·입력 누설을 빼면 보장 범위가 아닌 명목값만 얻는다.

실습은 전원 없는 계산부터 시작한다. 이 문서는 전원 장치·상용 전압·배터리 팩의 제작 지침이 아니다. 실물을 연결할 때는 부품 정격·전류 제한·접지·계측기 안전 조건을 별도로 확인해야 한다.

## 응용 (Applications)

센서 출력 읽기, 스위치 풀업, RC 필터, ADC 입력의 안정화에 연결된다. 분배기 출력의 부하 효과를 이해하면 “ADC가 값을 바꾼다”는 현상을 버퍼·입력 임피던스 문제로 분리할 수 있다.

## 흔한 오해 (Common Misunderstandings)

- 전압만 같으면 연결 가능하다: 전류 공급 능력, 공통 기준, 허용 입력 범위도 필요하다.
- 1 시정수 뒤 충전이 끝난다: 약 63.2% 도달이다.
- 디지털 입력에는 전류가 전혀 흐르지 않는다: 정적 누설과 전환 시 충전 전류를 구분해야 한다.

## TMI

- 접지는 이름이 아니라 회로의 기준과 연결 구조다. 서로 다른 장치의 기준 전위가 같다는 보장은 없다.
- 저항값을 모두 크게 하면 분배 비율은 같아도 부하·누설·잡음에 대한 민감도가 달라진다.

## 연습 / 확인 문제 (Exercises)

1. 위 분배기의 부하를 20kΩ으로 바꾸면? **해설:** 하단 등가는 약 6.667kΩ, 출력은 1.32V다. 무부하값 1.65V보다 작아야 한다.
2. 1kΩ·1µF 회로를 2kΩ·1µF로 바꾸면 90% 도달 시간은? **답:** 약 4.605ms. 정상상태 전압은 이상적 무부하 조건에서 같다.
3. 명목값 1.65V를 ADC 입력 보장값이라고 보고하면 무엇이 빠졌는가? **판단 기준:** 부하, 소자 오차, ADC 획득 시간과 입력 모델 중 둘 이상을 설명한다.
