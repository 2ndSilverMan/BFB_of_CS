# 사용법 (How to Use)

## If You Want to Learn

1. [학습 로드맵 (Roadmaps)](../Roadmaps/)에서 자신의 목적에 맞는 경로를 고른다.
2. 각 로드맵이 가리키는 분야별 README를 따라간다.
3. 모르는 선수지식은 [기초 지식 (Foundations)](../Foundations/)로 돌아가 확인한다.

## If You Want to Search

1. 용어는 [용어 사전 (Glossary)](../Reference/Glossary.md)에서 찾는다.
2. 알고리즘은 [알고리즘 색인 (Algorithms Index)](../Reference/Algorithms-Index.md)에서 찾는다.
3. 자료구조는 [자료구조 색인 (Data Structures Index)](../Reference/Data-Structures-Index.md)에서 찾는다.
4. 표기법은 [표기법 (Notation)](../Reference/Notation.md)을 확인한다.

## If You Want to Contribute

1. [주제 템플릿 (Topic Template)](../Templates/Topic-Template.md)을 기준으로 문서를 만든다.
2. 문서 상단에 Level, Prerequisites, Related Topics, Status를 적는다.
3. 같은 주제를 설명하는 문서가 이미 있는지 먼저 확인한다.
