## 사용 기준

- 도서는 한 분야를 체계적으로 공부할 수 있는 교재를 우선한다.
- 강의는 공개 접근 가능하고 커리큘럼이 안정적인 자료를 우선한다.
- 논문은 역사적 중요도, 기초 개념 형성, 현대 시스템/모델에 미친 영향을 기준으로 고른다.
- `Link` 열은 원문, 공식 강의, 출판사 페이지처럼 장기적으로 유지될 가능성이 높은 링크가 확인될 때만 추가한다.
