## A

**Activation Function (활성화 함수)**: 신경망 뉴런의 출력을 결정하는 비선형 함수. ReLU, Sigmoid, Tanh, GELU 등이 있다.

**Algorithm (알고리즘)**: 문제를 해결하는 단계적 절차. 입력을 받아 유한 시간 내에 출력을 생성한다.

**Amortized Analysis (분할 상환 분석)**: 단일 연산이 아닌 연산 시퀀스 전체의 평균 비용을 분석하는 방법.

**Attention Mechanism (어텐션 메커니즘)**: 입력의 어느 부분에 집중할지를 학습하는 신경망 구조. Transformer의 핵심.

**Autoencoder (오토인코더)**: 입력을 압축된 잠재 표현(인코딩)으로 변환한 뒤 원래 입력을 재구성(디코딩)하는 신경망.

---

## B

**Backpropagation (역전파)**: 신경망에서 오차를 출력층에서 입력층 방향으로 전파하며 가중치 기울기를 계산하는 알고리즘.

**Batch Normalization (배치 정규화)**: 각 미니배치 내에서 레이어 입력을 정규화해 학습을 안정화하는 기법.

**Bayes' Theorem (베이즈 정리)**: 사전 확률과 우도를 이용해 사후 확률을 계산하는 정리. P(A|B) = P(B|A)P(A) / P(B).

**Bias-Variance Tradeoff (편향-분산 트레이드오프)**: 모델의 복잡도가 높아질수록 편향은 줄지만 분산이 늘어나는 관계.

**Big-O Notation (빅오 표기법)**: 입력 크기 n이 커질 때 시간이나 공간 사용량의 점근적 상한을 나타내는 표기법. 최악/평균/최선 중 어떤 경우인지 문맥에서 명시해야 한다.

**Binary Search (이진 탐색)**: 정렬된 배열에서 중간 값을 기준으로 탐색 범위를 절반씩 줄여 값을 찾는 알고리즘.

**Binary Search Tree (이진 탐색 트리, BST)**: 왼쪽 서브트리 < 루트 < 오른쪽 서브트리 순서를 유지하는 이진 트리.

---

## C

**Cache (캐시)**: 자주 사용하는 데이터를 빠른 저장소에 임시로 보관하는 구조.

**CAP Theorem (CAP 정리)**: 분산 시스템은 일관성(Consistency), 가용성(Availability), 분단 허용성(Partition tolerance) 세 가지를 동시에 만족할 수 없다는 정리.

**Compiler (컴파일러)**: 고수준 언어로 작성된 소스 코드를 기계어 또는 다른 언어로 변환하는 프로그램.

**Complexity Class (복잡도 클래스)**: 계산 자원(시간, 공간)에 따라 문제를 분류하는 집합. P, NP, PSPACE 등.

**Concurrency (동시성)**: 여러 작업이 겹치는 시간 동안 진행되는 것. 실제로 동시에 실행되지 않아도 된다. → Parallelism과 구분.

**Context Window (컨텍스트 윈도우)**: LLM이 한 번에 처리할 수 있는 최대 토큰 수.

**Convolution (합성곱)**: 두 함수를 겹쳐 새로운 함수를 만드는 연산. CNN에서 이미지 특징을 추출하는 데 사용한다.

**Cross-Entropy Loss (교차 엔트로피 손실)**: 분류 문제에서 예측 분포와 실제 분포의 차이를 측정하는 손실 함수.

---

## D

**Data Structure (자료구조)**: 데이터를 효율적으로 저장하고 접근하기 위한 방법.

**Deadlock (교착 상태)**: 두 개 이상의 프로세스가 서로 상대방이 가진 자원을 기다리며 무한히 멈춰있는 상태.

**Decision Tree (결정 트리)**: 데이터를 특징 기준으로 분기하며 분류 또는 회귀하는 트리 형태의 모델.

**Deep Learning (딥러닝)**: 여러 층의 신경망을 이용해 데이터에서 계층적 표현을 학습하는 머신러닝의 한 분야.

**Diffusion Model (확산 모델)**: 데이터에 점진적으로 노이즈를 추가하는 과정을 역방향으로 학습하는 생성 모델.

**Distributed System (분산 시스템)**: 네트워크로 연결된 여러 컴퓨터가 하나의 시스템처럼 동작하는 구조.

**Dynamic Programming (동적 프로그래밍, DP)**: 문제를 부분 문제로 나누고 결과를 메모이제이션하여 중복 계산을 피하는 알고리즘 설계 기법.

---

## E

**Embedding (임베딩)**: 이산적인 객체(단어, 사용자 등)를 연속적인 벡터 공간에 매핑하는 표현. Word2Vec, BERT 임베딩 등.

**Entropy (엔트로피)**: 확률 분포의 불확실성을 측정하는 값. H(X) = -Σ p(x) log p(x).

**Epoch (에폭)**: 전체 학습 데이터를 한 번 순회하는 학습 단계.

**Eigenvalue / Eigenvector (고유값 / 고유벡터)**: 행렬 A에 대해 Av = λv를 만족하는 벡터 v와 스칼라 λ.

---

## F

**Fine-tuning (파인튜닝)**: 사전학습된 모델을 특정 태스크에 맞게 추가 학습시키는 방법.

**Floating Point (부동소수점)**: 실수를 컴퓨터에서 근사 표현하는 방식. IEEE 754 표준. 정밀도 한계가 수치 안정성 문제를 일으킬 수 있다.

---

## G

**GAN (Generative Adversarial Network)**: 생성자와 판별자가 서로 경쟁하며 학습하는 생성 모델.

**Gradient (그래디언트)**: 다변수 함수의 각 입력 변수에 대한 편미분 벡터. 함수가 가장 빠르게 증가하는 방향을 가리킨다.

**Gradient Descent (경사 하강법)**: 함수의 기울기 반대 방향으로 파라미터를 조금씩 이동하며 최솟값을 찾는 최적화 방법.

**Graph (그래프)**: 정점(Vertex)과 간선(Edge)으로 구성된 자료구조. 방향/무방향, 가중치 유무로 분류.

---

## H

**Hash Function (해시 함수)**: 임의 크기의 데이터를 고정 크기의 값으로 매핑하는 함수.

**Hash Table (해시 테이블)**: 해시 함수를 이용해 키-값 쌍을 저장하는 자료구조. 평균 O(1) 탐색.

**Heap (힙)**: 부모 노드가 자식 노드보다 크거나(최대 힙) 작은(최소 힙) 완전 이진 트리. 우선순위 큐 구현에 사용.

**Hyperparameter (하이퍼파라미터)**: 학습 과정을 제어하는 파라미터. 학습률, 배치 크기, 레이어 수 등. 모델이 학습으로 갱신하지 않는다.

---

## I

**Instruction Tuning (인스트럭션 튜닝)**: LLM이 자연어 명령을 잘 따르도록 (명령, 응답) 쌍 데이터로 파인튜닝하는 방법.

**Interrupt (인터럽트)**: CPU가 현재 작업을 잠시 중단하고 외부 이벤트(I/O 완료, 타이머 등)를 처리하도록 하는 신호.

---

## K

**Kernel (커널)**: ① OS 커널: 하드웨어와 소프트웨어 사이의 핵심 인터페이스. ② 합성곱 커널: 이미지 특징 추출에 사용되는 필터 행렬. ③ SVM 커널: 저차원 데이터를 고차원으로 암묵적으로 매핑하는 함수.

---

## L

**Latent Space (잠재 공간)**: 데이터의 압축된 내부 표현이 존재하는 저차원 공간. VAE, GAN, 오토인코더에서 사용.

**Layer (레이어)**: 신경망에서 동일한 유형의 연산을 수행하는 단위. 입력층, 은닉층, 출력층으로 구성.

**Learning Rate (학습률)**: 경사 하강법에서 파라미터를 업데이트할 때의 보폭 크기.

**Linked List (연결 리스트)**: 각 노드가 데이터와 다음 노드의 포인터를 가지는 선형 자료구조.

**Loss Function (손실 함수)**: 모델의 예측과 실제 값의 차이를 수치화하는 함수. 학습 목표.

---

## M

**Machine Learning (머신러닝)**: 데이터에서 규칙을 자동으로 학습하는 AI의 한 분야.

**MDP (Markov Decision Process)**: 상태, 행동, 전이 확률, 보상으로 정의되는 순차적 의사결정 프레임워크.

**Mutex (뮤텍스)**: 상호 배제(Mutual Exclusion)를 위한 잠금 기구. 하나의 스레드만 임계 영역에 진입하도록 보장.

---

## N

**Neural Network (신경망)**: 뇌의 뉴런을 모방해 레이어로 연결된 수학적 함수들의 집합.

**NP (Nondeterministic Polynomial time)**: 해를 다항 시간에 검증할 수 있는 결정 문제의 집합.

**NP-Complete (NP-완전)**: NP에 속하며, NP의 모든 문제가 다항 시간에 환원될 수 있는 가장 어려운 NP 문제.

**NP-Hard**: NP-Complete를 포함하며, NP의 모든 문제가 환원 가능하지만 해 자체의 검증이 다항 시간에 가능하지 않을 수 있는 문제.

---

## O

**Operating System (운영체제)**: 하드웨어 자원을 관리하고 애플리케이션에게 추상화된 인터페이스를 제공하는 소프트웨어.

**Overfitting (과적합)**: 모델이 훈련 데이터에는 잘 맞지만 새 데이터에는 잘 일반화되지 않는 현상.

---

## P

**P (문제 클래스)**: 결정론적 튜링 머신이 다항 시간에 풀 수 있는 결정 문제의 집합.

**Paging (페이징)**: 물리 메모리를 고정 크기의 프레임으로, 가상 메모리를 같은 크기의 페이지로 나눠 관리하는 메모리 관리 방법.

**Parallelism (병렬성)**: 여러 작업이 물리적으로 동시에 실행되는 것. → Concurrency와 구분.

**Pointer (포인터)**: 메모리 주소를 값으로 가지는 변수.

**Process (프로세스)**: 실행 중인 프로그램의 인스턴스. 독립된 메모리 공간을 가진다.

**Prompt (프롬프트)**: LLM에게 제공하는 입력 텍스트. 모델의 동작을 유도한다.

---

## Q

**Queue (큐)**: FIFO(First In First Out) 원칙으로 동작하는 선형 자료구조.

---

## R

**RAG (Retrieval-Augmented Generation)**: LLM이 외부 지식 베이스에서 관련 정보를 검색해 응답 생성에 활용하는 방법.

**Recursion (재귀)**: 함수가 자기 자신을 호출하는 프로그래밍 기법.

**Regularization (정규화)**: 과적합을 방지하기 위해 모델 복잡도에 패널티를 부여하는 방법. L1(Lasso), L2(Ridge) 등.

**Reinforcement Learning (강화학습)**: 에이전트가 환경과 상호작용하며 보상을 최대화하는 정책을 학습하는 방법.

**RLHF (Reinforcement Learning from Human Feedback)**: 인간의 선호도 피드백을 이용한 강화학습으로 LLM을 정렬하는 방법.

---

## S

**Semaphore (세마포어)**: 정수 카운터를 이용한 동기화 기구. 뮤텍스보다 일반적.

**Softmax**: 벡터를 합이 1인 확률 분포로 변환하는 함수. 분류 모델의 출력층에 사용.

**Sorting (정렬)**: 데이터를 정해진 기준에 따라 순서대로 재배치하는 작업. 이진 탐색, 중복 제거, 그룹화의 전처리로 자주 쓰인다.

**Stack (스택)**: LIFO(Last In First Out) 원칙으로 동작하는 선형 자료구조.

**SVD (Singular Value Decomposition, 특이값 분해)**: 행렬 A를 A = UΣVᵀ 형태로 분해하는 방법. 차원 축소, 추천 시스템에 활용.

---

## T

**TCP (Transmission Control Protocol)**: 신뢰성 있는 연결 지향 전송 프로토콜. 순서 보장, 오류 수정.

**Thread (스레드)**: 프로세스 내에서 실행되는 실행 단위. 같은 프로세스의 스레드들은 메모리를 공유한다.

**Time Complexity (시간 복잡도)**: 알고리즘이 입력 크기 n에 따라 수행하는 연산 횟수. Big-O 표기법으로 나타낸다.

**Tokenization (토크나이제이션)**: 텍스트를 모델이 처리할 수 있는 단위(토큰)로 분할하는 과정.

**Transformer**: 자기 어텐션(self-attention) 메커니즘을 기반으로 한 딥러닝 아키텍처. GPT, BERT의 기반.

**Transfer Learning (전이 학습)**: 한 태스크에서 학습한 지식을 다른 태스크에 재활용하는 방법.

**Turing Machine (튜링 머신)**: 계산 가능성을 정의하는 이론적 계산 모델. 무한한 테이프와 상태 전이 함수로 구성.

---

## U

**Underfitting (과소적합)**: 모델이 너무 단순해서 훈련 데이터도 잘 학습하지 못하는 현상.

---

## V

**VAE (Variational Autoencoder)**: 잠재 공간의 확률 분포를 학습하는 생성 모델. 재매개변수화 트릭(reparameterization trick)을 사용.

**Virtual Memory (가상 메모리)**: 실제 물리 메모리보다 큰 주소 공간을 프로세스에 제공하는 메모리 관리 기법.

---

## W

**Weight (가중치)**: 신경망에서 연결 강도를 나타내는 학습 가능한 파라미터.
