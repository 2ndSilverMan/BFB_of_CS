# 인간과 컴퓨터의 상호작용

> 사용자·과업·환경을 분석하고 상호작용을 설계·평가한다. UI 구현 기술이나 시각 디자인만을 뜻하지 않는다.

**선수지식**: 특정 프로그래밍 언어는 필수가 아님, [확률과 통계](../../Math/Probability-Statistics/) (정량 평가 시)

## 현재 가용성

아래 등록 주제에 `Draft` 본문이 있다. 개념·원리·구체 사례·확인 문제와 판단 기준·직접 출처·재작성 메모를 포함한다. `Planned`는 아직 본문이 없는 예정 항목에만 사용한다. 초안이 있다는 것은 분야 전체의 내용·실습·연구 깊이가 확보됐다는 뜻이 아니다. 각 문서의 확인 상태에서 실제 실행한 계산과 미실시한 실험을 구분한다.

## 학습 확인 목표

프로토타입의 평가 계획과 성공 기준을 작성한다. 실제 참여자 모집 없이도 가상 사례 분석과 접근성 점검을 할 수 있으며, 이를 실제 사용자 연구 결과로 표현하지 않는다.
