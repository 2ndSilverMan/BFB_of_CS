# 그래픽스와 상호작용

> 시각적 결과를 생성하는 그래픽스와 사람의 사용 경험을 설계·평가하는 HCI를 별도 하위 영역으로 다룬다.

## 현재 가용성

두 영역의 전용 주제 본문은 현재 Planned다. 기존 수학·프로그래밍·테스트의 Draft 이상 문서는 하위 README에서 연결한다. 관련 본문이 있다는 것만으로 그래픽스 또는 HCI 경로가 완성된 것은 아니다.

| 분야 | 범위 | 시작 조건 |
|---|---|---|

## 학습 순서

그래픽스와 HCI는 서로의 필수 선행 경로가 아니다. 관심 분야에서 시작하고 시각화·상호작용 시스템을 만들 때 연결한다.
