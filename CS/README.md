# 컴퓨터공학 (Computer Science)

> 컴퓨터공학 핵심 전공 지식.

`CS`는 컴퓨터가 어떻게 계산하고, 저장하고, 통신하고, 프로그래밍 언어와 시스템을 구성하는지 다룬다.
