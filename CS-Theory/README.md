> 계산이란 무엇인가, 언어는 어떻게 설계되는가, 컴파일러는 어떻게 동작하는가.

**선수지식**: [Math/Discrete/](../Math/Discrete/), [Algorithms/](../Algorithms/)

| 서브섹션 | 내용 | 선수지식 |

| [Computation-Theory/](Computation-Theory/) | 오토마타, 튜링 머신, 결정 불가능성, P vs NP | 이산수학, 알고리즘 |
