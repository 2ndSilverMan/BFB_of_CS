# 전체 지식 범위와 학습 역량 (Curriculum Coverage)

> 특정 진로의 필수 과목 목록이 아니라, 여러 경로를 구성할 수 있는 지식 기반의 범위·재료·공백을 관리한다.

## 판정 범위

2026-09-18 구조 개편의 초기 매핑이다. 기존 목차와 대표 본문의 학습 범위를 연결한 것으로, 524개 본문의 사실·증명·연습 문제를 전부 평가한 결과가 아니다. 아래의 **부분 확보**는 관련 본문이 있다는 뜻이며 해당 영역을 충분히 가르칠 수 있다는 판정이 아니다. **계획만**은 전용 본문 없이 목차와 인접 재료만 있는 상태다. 미기재 세부 분야도 남아 있으므로 완전성 비율을 산출하지 않는다.

- [Preparation-Inventory.md](Preparation-Inventory.md): 실제 본문의 출처·예제 후보·메모 존재 여부.
- 이 문서: 지식 영역과 학습 목표의 누락·깊이 부족.
- [Coverage-Matrix.md](Coverage-Matrix.md): 기존 선택 경로에 필요한 문서.
- [Content-Backlog.md](Content-Backlog.md): 공백을 보강하는 작업 묶음.
- [분야별 경로](../Roadmaps/Domain-Paths.md): 학습자의 출발점·선수지식·산출물·분야 이동.

## 범위 기준과 해석

[CS2023 지식 영역](https://csed.acm.org/knowledge-areas/)의 17개 영역을 빠짐없이 비교 대상으로 둔다. [최종 보고서](https://csed.acm.org/final-report/)는 학부 CS 범위를 점검하는 출발점이지 모든 대학원·전문직 역량의 완전 목록이 아니다. 아래 학습 목표와 파일 대응은 저장소 자체의 편집 판단이며 공식 교육과정과의 동등성 인증이 아니다.

컴퓨터공학의 하드웨어·소프트웨어 설계와 수학·과학 기반은 [ABET 2026–2027 공학 프로그램 기준](https://www.abet.org/accreditation/accreditation-criteria/criteria-for-accrediting-engineering-programs-2026-2027/)도 참고한다. 연구·교육 영역은 저장소의 추가 범위다. 누구에게나 같은 전공 심화를 강제하거나 학위·교수 직위를 학습 깊이로 환산하지 않는다.

## 깊이는 사람의 신분이 아니라 학습 목표로 구분

| 층위 | 필요한 재료 | 다음 층위로 가기 전 확인 |
|---|---|---|
| 입문 | 최소 선수지식, 동기, 용어, 작은 사례 | 예를 들고 인접 개념과 구분한다 |
| 핵심 | 정의, 작동 원리, 계산·구현·분석, 해설 있는 문제 | 새로운 작은 사례에 적용한다 |
| 심화 | 증명·대안·비용·실패 조건, 분야 간 연결 | 가정이 바뀔 때 결과를 설명한다 |
| 연구 연결 | 주요 문헌, 방법, 한계·논쟁, 재현·확장 질문 | 근거와 미해결 질문을 분리한다 |

이 층위는 편집 기준이며 기존 Level/Depth/Status 메타데이터 값을 바꾸지 않는다. 긴 본문은 후속 문서로 나누고 선수지식 링크를 연결한다. 모든 주제에 억지로 미해결 문제를 만들거나 코드를 넣지 않는다.

## 보강과 재평가 규칙

1. 모든 영역에 대해 범위·진입점·깊이·학습 확인·근거·연결성의 부족분을 따로 기록한다. 문서 개수로 평균 내어 빈 분야를 가리지 않는다.
2. 작업 묶음은 신규 공백의 진입 자료, 기존 본문의 깊이 보강, 공통 선수지식 연결을 함께 다룬다. 특정 경로의 완성을 다른 분야 착수 조건으로 두지 않는다.
3. 먼저 위험한 오류와 끊어진 선수지식을 고친다. 이후 전용 본문 없는 영역과 기본 학습 확인 수단이 없는 영역을 우선한다. 여러 분야에 도움 되는 주제도 함께 고른다.
4. 위 범위의 세부 주제를 실제 파일로 계획할 때 해당 README와 백로그에 등록한다. 범위 문구만 있는 항목은 등록된 Planned 파일 수에 포함하지 않는다.
5. 자료를 확보하면 이 표의 링크·부족분을 갱신하고 재작성 메모에 확인 범위를 남긴다. 본문·출처·예제·해설을 실제로 확인하기 전에는 영역을 완성으로 표시하지 않는다.
6. 사람 검토와 Complete 승격은 준비 단계의 목표에 포함하지 않는다. 자동 검증은 링크·목록·계획의 일관성을 검사하며 학문적 충분성을 판정하지 않는다.
